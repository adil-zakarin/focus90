# Фокус 90

Открыть: https://adil-zakarin.github.io/focus90/

Один фокус на 90 дней. Без аккаунтов и сервера: данные лежат только на телефоне.

## Как пользоваться

1. **Разбор**: выгрузи всё из головы, по одной мысли на строку, потом разложи каждую по 4 корзинам.
2. **Фокус**: оцени кандидатов (важность × энергия × реальность), выбери одного и запиши, что значит «готово».
3. **Сегодня**: одно главное дело на день, 3 задачи на неделю, таймер на 15 минут.
4. **«+»**: любая новая мысль сразу уходит во входящие, её не нужно держать в голове.
5. **Раз в неделю**: недельный обзор (кнопка появится сама).

## Как поставить на телефон

PWA нужен HTTPS. Самый простой вариант:

1. Открой https://app.netlify.com/drop и перетащи туда папку `focus90`.
2. Открой полученную ссылку на телефоне.
3. iPhone (Safari): «Поделиться» → «На экран „Домой“». Android (Chrome): меню ⋮ → «Установить приложение».

Подойдут и GitHub Pages, и Vercel: нужен любой статический хостинг.

## Обновление

После правок файлов увеличь версию в `sw.js` (`focus90-v1` → `focus90-v2`). Иначе телефон покажет старую версию из кэша.

## Локальный запуск

```bash
python3 -m http.server 4173 --directory focus90
```
